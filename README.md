# Aura Art Landing Page

A modern, production-ready Next.js 15 landing page with Tailwind CSS v3, SEO optimization, and Lucide icon favicon.

## Features

- ✅ Next.js 15 with App Router
- ✅ TypeScript
- ✅ Tailwind CSS v3
- ✅ SEO meta tags (Open Graph, Twitter Cards)
- ✅ Lucide icon favicon
- ✅ Custom fonts (Inter, Space Grotesk, JetBrains Mono)
- ✅ Responsive design
- ✅ Custom cursor effects
- ✅ Scroll animations
- ✅ Typewriter effect

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
